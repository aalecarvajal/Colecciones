# Colecciones en Java

Ejercicios de práctica con las estructuras de datos de Java, hechos en el Bootcamp Desarrollador Java Full Stack de Generation México. Los archivos incluyen comentarios con mis notas de clase.

## Ejercicios

| Clase | Estructura | Qué hace |
|---|---|---|
| `ArrayPrimitivo` | Arreglo de `int` | Recorre 100 números con `for` para calcular la suma, el promedio, el máximo y el mínimo. |
| `ArrayListC` | `ArrayList<Double>` | Pide 5 calificaciones con `Scanner` y calcula el promedio y la calificación más alta. |
| `HashMapC` | `HashMap<String, Integer>` | Guarda edades por nombre y usa `put`, `get`, `remove`, `size` y `keySet`. |
| `HashSetC` | `HashSet<String>` | Valida si un nombre de usuario está disponible con `contains`, sin permitir duplicados. |

## Cómo ejecutarlo

Abre el proyecto en IntelliJ IDEA y ejecuta la clase que quieras probar. Cada una tiene su propio método `main`.
